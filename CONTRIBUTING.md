# Contributing to ReStyle
To ensure smooth collaboration, please follow this workflow:

1. **Fork the repository:** Copy the project to your own account and clone it locally.
2. **Create a branch:** Never work directly on the `main` branch. Use descriptive names (`git checkout -b <bereich>/<agent>/<typ>/<TICKET>-<ticketnummer>-<kurze-beschreibung>`).
3. **Test locally:** Ensure your code works and the app starts without errors.
4. **Open a Pull Request (PR):** Submit your changes against our `main` branch. Briefly describe in your PR which problem was solved or which feature was added.
